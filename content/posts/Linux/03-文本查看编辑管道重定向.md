> [Linux 入门指南](./00-Linux入门指南.md) · 第三章：查看、筛选和编辑文本。

Linux 中的配置和日志大多可以按文本处理。常见工作并不复杂：打开文件，找到相关内容，保留需要的结果，再进行编辑。

本文按**查看 → 搜索 → 统计与组合 → 保存结果 → 编辑**的顺序展开。Shell 语法以 Bash 为例，文件名和目录名均为示例。

## 一、根据文件大小选择查看方式

| 需求 | 常用命令 | 适用情况 |
| --- | --- | --- |
| 输出完整内容 | `cat` | 内容较短的文本文件 |
| 分页阅读并搜索 | `less` | 配置、长文本、已有日志 |
| 查看开头 | `head` | 快速确认格式或文件头 |
| 查看结尾 | `tail` | 查看最近写入的日志 |
| 持续跟踪新增内容 | `tail -f`、`tail -F` | 观察运行中的日志 |

### cat：直接输出内容

```bash
cat app.conf
cat -n app.conf
```

| 选项 | 作用 |
| --- | --- |
| `-n` | 给所有输出行编号 |
| `-b` | 只给非空行编号 |
| `-s` | 将连续空行压缩为一行 |

`cat` 还可以连接多个文件并输出：

```bash
cat part-1.txt part-2.txt
```

它不会主动分页。文件较大时，使用 `less` 更便于阅读。

### less 与 more：分页阅读

```bash
less app.log
more app.log
```

`more` 提供基本分页功能；需要前后浏览和搜索时，通常使用 `less`。

| 按键 | 在 `less` 中的作用 |
| --- | --- |
| 空格、`f` | 向后翻一页 |
| `b` | 向前翻一页 |
| `g`、`G` | 跳到开头、结尾 |
| `/关键字` | 向后搜索 |
| `n`、`N` | 沿搜索方向、反方向跳转匹配 |
| `q` | 退出 |

### head 与 tail：只看需要的片段

```bash
head -n 20 app.log
tail -n 50 app.log
```

不指定 `-n` 时，两者默认显示 10 行。

实时查看日志：

```bash
tail -f app.log
```

如果日志会被轮转、重命名或重新创建，GNU `tail` 的 `-F` 往往更合适：

```bash
tail -F app.log
```

`-f` 默认跟随已打开的文件描述符；`-F` 按文件名跟踪并重试打开。按 `Ctrl+C` 停止跟踪。

## 二、搜索内容与查找文件

**`grep` 搜索文件里的内容，`find` 按条件查找文件和目录。** 两者解决的问题不同。

### grep：筛选匹配的行

```bash
grep -n 'ERROR' app.log
grep -i 'failed' app.log
grep -r -n 'server_name' /etc/nginx
```

| 选项 | 作用 |
| --- | --- |
| `-n` | 显示行号 |
| `-i` | 忽略大小写 |
| `-v` | 输出不匹配的行 |
| `-r` | 递归搜索目录 |
| `-F` | 按固定字符串匹配 |
| `-E` | 使用扩展正则表达式 |
| `-c` | 对每个输入文件统计匹配行数 |

普通 `grep` 使用正则表达式。搜索 IP、文件名等字面文本时，可以使用 `-F`，避免把 `.` 等字符解释为正则符号：

```bash
grep -nF '192.168.1.10' app.log
```

常见正则写法：

| 表达式 | 含义 |
| --- | --- |
| `^root` | 以 `root` 开头 |
| `bash$` | 以 `bash` 结尾 |
| `^$` | 空行 |
| `^[[:space:]]*#` | 可有前导空白的注释行 |

例如，排除以 `#` 开头的注释行和空白行：

```bash
grep -Ev '^[[:space:]]*(#|$)' app.conf
```

这里约定 `#` 表示注释；不同配置格式的注释规则可能不同。简单使用 `grep -v '#'` 会排除所有含 `#` 的行，也可能误删有效内容。

### find：按名称、类型和大小查找

```bash
find /etc -type f -name '*.conf'
find "$HOME" -type d -name 'logs'
find /var/log -type f -size +100M
```

| 条件 | 含义 |
| --- | --- |
| `-name '*.conf'` | 名称符合模式，区分大小写 |
| `-iname '*.conf'` | 名称符合模式，忽略大小写 |
| `-type f` | 普通文件 |
| `-type d` | 目录 |
| `-size +100M` | 文件大小超过 100 MiB |

`'*.conf'` 需要加引号，让模式交给 `find` 处理，避免先被当前 Shell 展开。查找时优先限定目录，减少无关结果和权限错误。

## 三、统计文本：wc

```bash
wc app.log
wc -l app.log
wc -m article.txt
```

| 选项 | 统计对象 |
| --- | --- |
| `-l` | 换行符数量，通常用来表示行数 |
| `-w` | 由空白分隔的词数 |
| `-c` | 字节数 |
| `-m` | 字符数，取决于字符编码和 locale |

`wc -l` 统计的是换行符。文件末尾没有换行时，结果可能比阅读时看到的文本行数少一。

中文字符通常占用多个字节，因此 `wc -c` 和 `wc -m` 的结果可能不同；`wc -w` 也不能直接当作中文字数统计。

只统计日志里包含 `ERROR` 的行，可以直接使用：

```bash
grep -cF 'ERROR' app.log
```

这里统计的是匹配行数，同一行出现多次 `ERROR` 仍只算一行。

## 四、常用文本加工：排序、去重与字段提取

查看和筛选之后，经常还需要汇总重复内容、提取某一列，或只展示替换后的文本。先选取结构稳定的数据，再组合工具，结果更容易解释。

### sort 与 uniq：统计重复行

假设 `status.txt` 每行保存一个状态名称，可以统计各状态出现的次数：

```bash
sort status.txt | uniq -c | sort -nr
```

`sort` 把相同内容排到一起；`uniq -c` 对相邻重复行计数；`sort -nr` 按数字从大到小排序。`uniq` 默认只合并相邻重复行，不会自动把文件中所有相同内容聚在一起。

若只需要不同的完整行，可以使用 `sort -u status.txt`。排序规则与 locale 有关，需要可复现的字节顺序时，可显式指定 `LC_ALL=C sort 文件`。

### cut 与 awk：按规则取字段

`/etc/passwd` 使用冒号分隔字段，提取第一列用户名：

```bash
cut -d ':' -f 1 /etc/passwd
```

`cut` 适合固定分隔符。对简单的空白分隔文本，`awk` 可以按字段处理：

```bash
awk '{print $1}' status.txt
```

这里的 `$1` 属于 awk 程序，表示输入行的第一个字段；单引号避免它被 Shell 当作自己的位置参数展开。

这些写法不能自动处理所有数据格式。带引号、转义或嵌套结构的 CSV、JSON 等，应使用了解对应格式的工具。

### sed：选行与替换展示

```bash
sed -n '1,20p' app.conf
sed 's/old/new/g' app.conf
```

第一条输出第 1 到 20 行；第二条逐行替换并输出。这里没有使用原地修改选项，所以原文件内容保持不变。

`sed` 的搜索部分使用正则表达式，替换部分也有自己的特殊字符规则。写回配置之前，先查看结果；不要把简单替换当作理解配置语法的编辑器。

## 五、管道：让命令接力处理文本

命令运行时，通常会涉及三个标准通道：

| 通道 | 编号 | 默认连接 |
| --- | --- | --- |
| 标准输入 | `0` | 终端输入 |
| 标准输出 | `1` | 终端显示 |
| 标准错误 | `2` | 终端显示 |

管道 `|` 把左边命令的**标准输出**连接到右边命令的**标准输入**：

```text
命令 A ──标准输出──→ 管道 ──标准输入──→ 命令 B
```

例如，从错误日志中继续筛选超时记录：

```bash
grep -F 'ERROR' app.log | grep -F 'timeout'
```

也可以边跟踪日志边筛选：

```bash
tail -F app.log | grep --line-buffered -F 'ERROR'
```

GNU `grep` 的 `--line-buffered` 可以减少管道缓冲带来的显示延迟。

普通 `|` 不会自动把标准错误传给下一个命令。如果需要合并错误输出，可以先使用 `2>&1`：

```bash
find /etc -type f -name '*.conf' 2>&1 | less
```

此时错误信息也会参与后续处理；是否合并，要看你需要保留什么结果。

## 六、重定向：把输出保存到文件

| 写法 | 含义 |
| --- | --- |
| `> 文件` | 标准输出覆盖写入文件 |
| `>> 文件` | 标准输出追加写入文件 |
| `2> 文件` | 标准错误覆盖写入文件 |
| `2>> 文件` | 标准错误追加写入文件 |
| `< 文件` | 从文件读取标准输入 |
| `> 文件 2>&1` | 将标准输出和标准错误写入同一文件 |

### 覆盖和追加

```bash
echo 'hello linux'
printf 'hello\n' > notes.txt
printf 'world\n' >> notes.txt
```

`echo` 适合简单输出；需要明确控制换行和格式时，使用 `printf` 更方便。`>` 会在命令运行前打开并截断目标文件，所以不要把同一个文件同时用作输入和覆盖输出，例如 `cat notes.txt > notes.txt` 会导致内容丢失。

### 重定向顺序会影响结果

```bash
ls /etc /not-exist > result.log 2>&1
```

先把标准输出连接到 `result.log`，再让标准错误指向同一个去处，所以两种输出都会进入文件。

如果交换顺序：

```bash
ls /etc /not-exist 2>&1 > result.log
```

标准错误先指向当时的标准输出，随后只有标准输出被改到文件。普通终端中，错误信息仍会显示在终端。

### 为什么 `sudo` 后的重定向仍会权限不足

重定向由当前 Shell 处理。`sudo 命令 > /etc/某文件` 只提升了命令的权限，没有提升当前 Shell 打开文件的权限。

需要向受保护文件写入时，可以让 `tee` 负责写文件。例如，下面的命令会覆盖目标文件：

```bash
printf '%s\n' 'APP_MODE=production' | sudo tee /etc/example-app.env
```

追加时使用 `tee -a`。修改已有配置前应先核对文件用途与内容。

## 七、命令替换：把输出放进另一个命令

Bash 使用 `$()` 执行内部命令，并用它的标准输出替换整个表达式：

```bash
printf '当前目录：%s\n' "$(pwd)"
cp -p app.conf "app.conf.bak-$(date +%Y%m%d-%H%M%S)"
```

第二条命令利用时间生成备份名称。双引号能避免替换结果被进一步按空白拆分或进行通配符展开。

反引号也能进行命令替换，但嵌套和转义不直观，日常书写优先使用 `$()`。

## 八、Vim：先掌握模式，再记操作

打开文件：

```bash
vim app.conf
```

| 模式 | 主要用途 | 进入方式 |
| --- | --- | --- |
| 普通模式 | 移动、复制、删除、撤销 | 打开文件后默认进入，或按 `Esc` 返回 |
| 插入模式 | 输入文本 | 普通模式下按 `i`、`a` 或 `o` |
| 命令行模式 | 保存、退出、替换、设置 | 普通模式下按 `:` |

Vim 还有可视模式等模式，入门时先熟悉上面三种即可。

### 普通模式常用操作

| 按键 | 用途 |
| --- | --- |
| `i`、`a` | 在光标前、后插入 |
| `o` | 在下一行新建一行并插入 |
| `gg`、`G` | 跳到首行、末行 |
| `50gg` | 跳到第 50 行 |
| `dd`、`10dd` | 删除当前行、从当前行起删除 10 行 |
| `yy`、`10yy` | 复制当前行、从当前行起复制 10 行 |
| `p` | 在光标后粘贴；复制整行时粘贴到下一行 |
| `u` | 撤销 |
| `Ctrl+R` | 重做 |
| `/关键字` | 搜索，随后用 `n`、`N` 跳转 |

### 保存、退出与替换

先按 `Esc`，再输入下面的命令并按回车：

| 命令 | 用途 |
| --- | --- |
| `:set number` | 显示行号 |
| `:set nonumber` | 隐藏行号 |
| `:w` | 保存 |
| `:q` | 退出；有未保存修改时会阻止退出 |
| `:wq` | 保存并退出 |
| `:q!` | 丢弃当前缓冲区未保存的修改并退出 |
| `:s/old/new/` | 替换当前行第一个匹配 |
| `:s/old/new/g` | 替换当前行全部匹配 |
| `:%s/old/new/gc` | 在全文逐个确认后替换 |

替换模式默认按正则表达式解释。批量修改配置时，带 `c` 逐项确认更便于核对范围。

## 九、命令速查

| 命令 | 用途 |
| --- | --- |
| `less 文件` | 分页查看 |
| `head -n 20 文件` | 查看前 20 行 |
| `tail -F 日志` | 按文件名持续跟踪日志 |
| `grep -nF '文本' 文件` | 按固定字符串搜索并显示行号 |
| `find 目录 -type f -name '*.conf'` | 查找配置文件 |
| `wc -l 文件` | 统计换行符数量 |
| `sort 文件` | 对文本行排序 |
| `uniq -c 文件` | 统计相邻重复行 |
| `cut -d 分隔符 -f 列号 文件` | 按分隔符提取字段 |
| `sed -n '1,20p' 文件` | 选取前 20 行 |
| `命令1 \| 命令2` | 将标准输出传给下一个命令 |
| `命令 > 输出.log 2>&1` | 合并保存标准输出和标准错误 |
| `printf '内容\n' >> 文件` | 追加文本 |
| `vim 文件` | 编辑文本 |
