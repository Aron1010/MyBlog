文件操作可以按一条清晰的顺序理解：**确认位置 → 查看目标 → 创建或整理 → 检查结果。** 命令本身通常很短，真正容易出错的是路径、覆盖规则和操作范围。

本文示例以 Linux 下的 Bash 和 GNU 常用工具为主。`a.txt`、`project` 等名称是示例目标，复制命令前应换成自己的实际路径。

## 一、先看清当前位置和目录内容

### pwd 与 cd：确认操作位置

```bash
pwd
cd "$HOME"
cd /var/log
cd ..
cd -
```

`pwd` 显示当前工作目录；`cd` 改变后续相对路径的起点。执行批量操作前，先确认当前位置，能避免把正确的命令用在错误的目录中。

### ls：查看文件和目录

```bash
ls
ls /etc
ls -lh
ls -la
ls -ld /etc
```

| 选项 | 用途 | 常见组合 |
| --- | --- | --- |
| `-l` | 显示权限、所有者、大小、时间等信息 | `ls -l` |
| `-h` | 使用易读的容量单位，通常配合 `-l` | `ls -lh` |
| `-a` | 显示全部条目，包括隐藏文件、`.` 和 `..` | `ls -la` |
| `-A` | 显示隐藏文件，省略 `.` 和 `..` | `ls -lA` |
| `-d` | 显示目录本身，不列出其内部条目 | `ls -ld /etc` |
| `-t` | 按修改时间排序，较新的在前 | `ls -lt` |

长格式输出示例：

```text
-rw-r--r-- 1 aron dev 1280 Jul 8 10:00 notes.txt
```

从左到右依次是文件类型与权限、硬链接数、所有者、所属组、大小、修改时间和名称。目录条目的大小并不等于目录内所有文件的总大小；查看目录占用要使用 `du`。

## 二、创建目录：mkdir

创建单个目录：

```bash
mkdir notes
```

一次创建多级目录：

```bash
mkdir -p project/logs/nginx
```

`-p` 会补建不存在的父目录；目标目录已经存在时也不会因此报错。但如果路径上的某一部分是普通文件，仍然无法创建目录。

在 Bash 中，可以利用大括号展开创建并列目录：

```bash
mkdir -p project/{bin,conf,logs,data}
```

对应结构为：

```text
project/
├── bin/
├── conf/
├── logs/
└── data/
```

大括号展开由 Shell 完成，并非 `mkdir` 自身的功能；并不是所有 Shell 都支持同样的写法。

## 三、创建空文件与更新时间戳：touch

```bash
touch notes.txt
touch app.log README.md
```

目标不存在时，`touch` 默认创建空文件；目标已经存在时，默认更新访问时间和修改时间，**不会清空原有内容**。

| 操作 | 对已有文件内容的影响 |
| --- | --- |
| `touch app.log` | 保留内容，更新时间戳 |
| `printf 'hello\n' > app.log` | 覆盖内容 |
| `printf 'hello\n' >> app.log` | 在末尾追加内容 |

因此，`touch` 适合准备空文件，不适合用来清空日志。

## 四、复制文件和目录：cp

基本形式：

```text
cp [选项] 源路径 目标路径
```

### 目标是否存在，会改变复制结果

假设 `a.txt` 是一个已有文件：

| 命令 | 目标状态 | 结果 |
| --- | --- | --- |
| `cp a.txt b.txt` | `b.txt` 不存在 | 创建副本 `b.txt` |
| `cp a.txt b.txt` | `b.txt` 是已有文件 | 默认可能覆盖其内容 |
| `cp a.txt backup/` | `backup` 是已有目录 | 在目录中生成 `a.txt` |

结尾写 `/` 可以清楚表达“这里应当是一个目录”。`cp` 不会自动创建缺失的父目录，应先用 `mkdir -p` 准备目标位置。

### 复制整个目录

```bash
cp -r project project-copy
```

如果 `project-copy` 不存在，会生成一个对应副本；如果它已经是目录，通常会在其中再创建或合并 `project`。复制前应确认目标是否已存在。

在 GNU `cp` 中，如果要把源目录的内容复制到一个已有目录，包括隐藏条目，可以写：

```bash
mkdir -p backup
cp -a project/. backup/
```

这里的 `project/.` 指定源目录内容，`-a` 采用归档复制方式。执行权限、所有权等属性能否完整保留，还取决于当前用户权限和目标文件系统。

### 常用选项

| 选项 | 作用 |
| --- | --- |
| `-r`、`-R` | 递归复制目录 |
| `-i` | 覆盖前询问 |
| `-p` | 尝试保留权限、所有权与时间戳等属性 |
| `-a` | 归档复制，递归并尽可能保留属性和链接关系 |
| `-f` | 目标文件无法打开时，尝试移除后重新创建 |

`-f` 不能绕过系统权限检查。需要人工确认覆盖时，直接使用 `-i` 更容易理解。

修改配置前，可以先复制一份备份：

```bash
cp -p app.conf "app.conf.bak-$(date +%Y%m%d-%H%M%S)"
```

## 五、移动与重命名：mv

`mv` 的用途由目标位置决定：目标仍在原目录时表现为重命名，目标在别处时表现为移动。

```bash
mv old.txt new.txt
mv app.log logs/
mv app.log logs/app-2026.log
```

目标目录需要事先存在；目标文件已经存在时，默认可能被覆盖。对重要文件可以使用交互确认：

```bash
mv -i app.conf app.conf.bak
```

| 选项 | 用途 |
| --- | --- |
| `-i` | 覆盖前询问 |
| `-n` | 不覆盖已有目标 |
| `-f` | 不因覆盖而询问，仍受权限限制 |
| `-u` | 源较新或目标不存在时才移动 |
| `-b` | 在覆盖目标前创建备份 |

这些选项以 GNU `mv` 为例，不同系统的支持情况可能不同。不要把 `-i`、`-n`、`-f` 混在一起依赖选项顺序，按实际意图选一种即可。

同一文件系统内的移动通常只是修改目录项；跨文件系统移动则通常需要先复制再删除，耗时和失败情形会有所不同。

## 六、删除文件与目录：rm 和 rmdir

### 删除文件

```bash
rm -i notes.txt
```

`-i` 会逐项询问。终端里的 `rm` 通常不会把文件放进桌面回收站，确认后就会移除对应目录项。

### 删除目录

只删除空目录：

```bash
rmdir empty-dir
```

删除目录及内部内容：

```bash
rm -r old-project
```

| 选项 | 含义 |
| --- | --- |
| `-r`、`-R` | 递归删除目录及其内容 |
| `-i` | 每次删除前询问 |
| `-f` | 不询问，并忽略不存在的目标 |

`-f` 不会绕过文件权限、只读文件系统等限制。使用递归删除时，先核对完整路径和内容：

```bash
pwd
ls -ld -- old-project
ls -A -- old-project
rm -ri -- old-project
```

`rm -ri` 适合数量较少、需要逐项确认的目标。大量文件应先明确操作范围，避免只凭目录名判断。

## 七、路径、通配符和特殊文件名

### 引号：把包含空格的名称作为一个参数

```bash
cp -i "meeting notes.txt" "meeting notes.bak"
```

没有引号时，空格会把文件名拆成多个参数。

### 通配符：先展开，再执行命令

```bash
ls *.log
```

在 Bash 默认设置下，`*.log` 匹配当前目录中以 `.log` 结尾的非隐藏条目。匹配通常由 Shell 完成，命令接收到的是展开后的名称列表。

操作范围越广，越应该先查看展开结果。`*` 默认不包含以 `.` 开头的名称，也不代表“所有文件，包括隐藏文件”。

### `--`：结束选项解析

对于以 `-` 开头的文件名，可以用 `--` 防止被识别为选项：

```bash
rm -i -- -draft.txt
```

也可以通过路径写法规避：

```bash
rm -i ./-draft.txt
```

## 八、命令速查

| 命令 | 用途 |
| --- | --- |
| `pwd` | 确认当前工作目录 |
| `ls -lh` | 查看详细信息与易读的文件大小 |
| `ls -ld 目录` | 查看目录本身的信息 |
| `mkdir -p a/b/c` | 创建多级目录 |
| `touch 文件` | 创建空文件或更新时间戳 |
| `cp -i 源文件 目标文件` | 复制文件，覆盖前确认 |
| `cp -a 源目录/. 目标目录/` | 复制目录内容并尽可能保留属性 |
| `mv -i 源 目标` | 移动或重命名，覆盖前确认 |
| `rmdir 目录` | 删除空目录 |
| `rm -i 文件` | 询问后删除文件 |
| `rm -ri 目录` | 递归删除并逐项确认 |
