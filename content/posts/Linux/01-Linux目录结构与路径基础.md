> [Linux 入门指南](./00-Linux入门指南.md) · 第一章：建立目录与路径的基本认识。

在终端里操作 Linux，首先要解决两个问题：**我现在在哪里，要操作的文件又在哪里。** 理解目录和路径之后，文件管理、日志查看与软件配置都会更容易上手。

本文从目录树讲起，再介绍路径写法和命令帮助。示例以 Linux 下的 Bash 为主；代码块不包含终端提示符，可以按需复制。文中的“文件名”“用户名”等中文内容表示需要替换的参数。

## 一、从目录树认识 Linux

Linux 把可访问的文件组织在同一棵目录树中，起点叫作**根目录**，写成 `/`。不同磁盘或分区可以挂载到目录树中的某个位置，通过路径访问。

```text
/
├── etc/          系统配置
├── home/         普通用户的家目录通常放在这里
│   └── aron/
│       ├── projects/
│       └── notes.txt
├── root/         root 用户的家目录
├── tmp/          临时文件
├── usr/          大量命令、库和共享资源
└── var/          日志、缓存等可变数据
```

例如，`/home/aron/notes.txt` 表示从根目录开始，依次进入 `home`、`aron`，最后找到 `notes.txt`。

### 常见目录各放什么

| 目录 | 主要用途 | 阅读时的理解重点 |
| --- | --- | --- |
| `/etc` | 系统与软件配置 | 修改前先确认文件用途并保留备份 |
| `/home` | 普通用户家目录的常见位置 | 具体位置由账号配置决定 |
| `/root` | root 用户的家目录 | 与根目录 `/` 是两个概念 |
| `/usr` | 大量系统命令、库和共享资源 | 不是普通用户的个人目录 |
| `/usr/local` | 本机管理员安装的软件与资源 | 常见于手动安装的软件 |
| `/bin`、`/sbin` | 基础命令与系统管理命令 | 部分系统将它们链接到 `/usr` 下 |
| `/var` | 日志、缓存、队列等可变数据 | 服务排查时经常访问 `/var/log` |
| `/tmp` | 临时文件 | 不适合保存需要长期保留的数据 |
| `/opt` | 附加软件的常见安装位置 | 是否使用取决于软件和部署约定 |
| `/dev` | 设备文件 | 例如磁盘、终端设备 |
| `/proc`、`/sys` | 内核与设备信息接口 | 大量内容由内核动态提供 |
| `/mnt`、`/media` | 挂载点的常见位置 | 用于访问挂载后的文件系统 |

不必一次记住全部目录。刚开始使用时，重点认识 `/home`、`/etc`、`/var/log` 和 `/tmp` 即可。

## 二、区分根目录、家目录和工作目录

| 概念 | 含义 | 示例 |
| --- | --- | --- |
| 根目录 | 整棵目录树的起点 | `/` |
| 家目录（HOME） | 当前用户的个人目录 | `/home/aron` |
| 当前工作目录 | 当前 Shell 所在的位置 | `/home/aron/projects` |

root 是管理员账号的名称，它的家目录通常是 `/root`。**root 用户、根目录 `/`、家目录 `/root` 不能混为一谈。**

登录终端后通常会进入自己的家目录，但启动方式或配置可能改变这一行为。判断当前位置，应查看命令输出：

```bash
pwd
```

可能得到：

```text
/home/aron/projects
```

查看当前用户的家目录：

```bash
printf '%s\n' "$HOME"
```

`$HOME` 是变量展开；`pwd` 显示的是当前工作目录，两者不一定相同。

## 三、绝对路径与相对路径

### 绝对路径：从根目录开始

绝对路径以 `/` 开头：

```text
/home/aron/projects/app.log
```

在同一文件系统视图中，它不依赖当前工作目录，适合明确指定配置文件、日志和脚本的位置。

### 相对路径：从当前目录开始

相对路径不以 `/` 开头：

```text
projects/app.log
```

假设当前目录是 `/home/aron`，这个相对路径就指向 `/home/aron/projects/app.log`；如果切换到了 `/tmp`，它就指向 `/tmp/projects/app.log`。

| 当前工作目录 | 使用的路径 | 对应位置 |
| --- | --- | --- |
| `/home/aron` | `projects/app.log` | `/home/aron/projects/app.log` |
| `/home/aron/projects` | `app.log` | `/home/aron/projects/app.log` |
| `/home/aron/projects` | `../notes.txt` | `/home/aron/notes.txt` |

排查“找不到文件”时，先运行 `pwd`，再判断所写路径是从哪里开始解析的。

## 四、常用路径写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 当前目录 | `./app.log` |
| `..` | 上一级目录 | `../notes.txt` |
| `../..` | 上两级目录 | `cd ../..` |
| `~` | 在 Bash 等 Shell 中展开为当前用户家目录 | `cd ~/projects` |
| `/` | 根目录 | `cd /` |

常见的目录切换：

```bash
cd /etc
cd ..
cd ~
cd
cd -
```

不带参数的 `cd` 回到 `$HOME`；`cd -` 返回上一次所在的目录，适合在两个位置之间来回切换。

### 为什么执行脚本时常写 `./`

```bash
./start.sh
```

这里的 `./` 明确指定当前目录下的脚本。直接输入 `start.sh` 时，Shell 通常会沿着 `PATH` 查找命令，并不会自动搜索当前目录。脚本还需要具备合适的执行权限和解释器配置。

### 路径中有空格怎么办

用引号把整个路径括起来：

```bash
cd "$HOME/My Notes"
ls -l "meeting notes.txt"
```

Bash 不会在引号内进行波浪号展开，因此 `"~/My Notes"` 不能按预期表示家目录；使用 `"$HOME/My Notes"` 更合适。

Linux 常用文件系统通常区分大小写，`Notes.txt` 与 `notes.txt` 可以是两个不同的文件。书写路径时要同时检查大小写、空格和拼写。

## 五、隐藏文件与用户配置

以 `.` 开头的文件或目录通常不会出现在普通 `ls` 输出中，例如 `.bashrc`、`.ssh` 和 `.vimrc`。

```bash
ls -a
ls -A
```

`-a` 显示全部条目，包括 `.` 和 `..`；`-A` 显示隐藏条目，但省略这两个特殊目录项。

隐藏只是默认的显示规则，不代表加密或访问保护。文件是否可读、可写，仍由权限等机制决定。

## 六、理解命令结构并查询帮助

大多数命令可以按下面的结构阅读：

```text
命令 [选项] [参数]
```

例如：

```bash
ls -lh /var/log
```

- `ls`：要执行的命令。
- `-lh`：选项，组合了长格式显示和易读的文件大小。
- `/var/log`：要操作的目标目录。

手册中的方括号 `[]` 通常表示可选内容，输入命令时不需要照抄方括号。

### 外部命令与 Shell 内置命令

查看命令属于哪一类：

```bash
type cd
type ls
```

`cd` 是 Shell 内置命令。Bash 内置命令可用 `help` 查询：

```bash
help cd
```

很多外部命令提供 `--help`，更详细的说明可以通过 `man` 查看：

```bash
ls --help
man ls
```

不同命令支持的选项可能不同，`--help` 并不是所有命令都通用。精简系统也可能未安装手册页。

在常见的 `man` 分页界面中，可以用 `/关键字` 搜索，按 `n` 查看下一个匹配，按 `q` 退出。

## 七、常见问题

| 现象 | 优先检查 |
| --- | --- |
| 提示 `No such file or directory` | 当前目录、路径拼写、大小写，以及目标是否存在 |
| 提示 `Permission denied` | 文件权限和上级目录的访问权限 |
| 输入脚本名后提示 `command not found` | 是否需要写 `./`，以及命令是否在 `PATH` 中 |
| 看不到 `.bashrc` 等文件 | 是否使用了 `ls -a` 或 `ls -A` |
| `cd` 后位置与预期不同 | 用 `pwd` 确认实际目录，再检查相对路径起点 |

## 八、命令速查

| 命令 | 用途 |
| --- | --- |
| `pwd` | 查看当前工作目录 |
| `printf '%s\n' "$HOME"` | 查看家目录路径 |
| `cd /目标目录` | 使用绝对路径切换目录 |
| `cd ..` | 返回上一级目录 |
| `cd` | 返回家目录 |
| `cd -` | 返回上一次所在的目录 |
| `ls -A` | 显示包含隐藏条目在内的目录内容 |
| `type 命令` | 查看命令的类型与解析结果 |
| `help cd` | 查询 Bash 内置命令帮助 |
| `man ls` | 查看命令手册 |
